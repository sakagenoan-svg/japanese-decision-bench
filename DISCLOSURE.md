# Disclosure

## Independence

This project is independently developed.

The benchmark protocol, labels, metrics, and evaluation criteria are defined before inspecting benchmark
results.

Any sponsorship, financial relationship, or other potential conflict of interest relevant to this project will
be disclosed here if applicable.

## Dataset drafting

Authored examples were drafted with the help of an LLM from Anthropic (Claude), and gold labels were assigned by
the maintainer. A Claude model is also available as a baseline provider. See the limitations in the README.
