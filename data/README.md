# Data

License: CC BY 4.0 ([LICENSE-DATA](../LICENSE-DATA)).

All texts are **synthetic**. They are set in a fictional peer-to-peer goods exchange service and contain no real
users, real names, real transaction IDs, real personal information, or real customer messages. Do not add real
user data to this directory.

Every file is generated by [`scripts/build_dataset.py`](../scripts/build_dataset.py). Edit the script, not the
JSONL files. The tests fail if the two differ.

## Files

## Row schema

```json
{
  "id": "t1-009",
  "task": "t1_moderation",
  "state": "取引ありがとうございました〜！さすが、発送が早いですね😊（3週間待ちました）",
  "context": null,
  "label": "harassment",
  "label_b": null,
  "agreed": null,
  "source": "llm_assisted",
  "variant_of": null,
  "variant_type": null,
  "note": "皮肉",
  "t3_base": true
}
```

| Field | Meaning |
|---|---|
| `state` | the text evaluated. For T4, this is the `target` utterance |
| `context` | T4 only: list of `{"speaker", "text"}` preceding the target. Sent as `{"context": ..., "target": state}` |
| `label` | gold label (maintainer) |
| `label_b`, `agreed` | second annotator's label and agreement; `null` until a second pass exists |
| `source` | `handwritten` / `llm_assisted` / `derived` |
| `variant_of`, `variant_type` | T3: base T1 id and variant kind. T5: clean id and `clean` / `medium` / `heavy` |
| `note` | phenomenon tag for analysis; never sent to models |
| `t3_base` | T1 only: pre-selected as a T3 base |

## Question file schema

```json
{"type": "choice", "instructions": "...",
 "options": [{"label": "harassment", "key": "嫌がらせ", "description": "..."}]}
{"type": "score", "instructions": "...", "levels": [{"value": 0, "description": "..."}]}
{"type": "binary", "instructions": "...", "criteria": {"true": "...", "false": "..."}}
```

`key` is the option name shown to the model, and `label` is the gold-label space used for scoring.
